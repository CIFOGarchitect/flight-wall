Data: live ADS-B feeds, tried in order — airplanes.live, adsb.lol, adsb.fi, AvioADSB, OpenSky Network (all free, no key). The status line shows which source is active. Callsign, rotor/fixed-wing type, altitude, speed, heading, distance and climb/descent. Coverage depends on volunteer receivers, so some aircraft may not appear. The free feed does not include origin/destination — that takes a paid flight-data service. Refreshes every 15 seconds. Favorites and your custom range live in this browser's own storage, so they work best when the file is opened directly rather than in a preview. Tip: open in your browser and press F11 for a full-screen flight wall. Smart TV: open this board from the TV's browser using your computer's network address (printed when the server starts) — same Wi-Fi, computer stays awake. When served by flight-wall-server.py, the board reads one aggregated feed built from all five sources at once. Controlling Center is approximate (nearest Center facility) — near a boundary, the true controlling Center may differ. Big display: a large single-aircraft view of the nearest aircraft above 15,000 ft AGL (approximate — Logan field elevation used as ground reference) — toggle it from the controls. Aircraft model shows beside the AGL figure when the feed provides it.
